## Task Descriptions and Results

### Task 1 — Problem Analysis

Identifies the billing inputs, outputs, constants, assumptions and validation rules. The program demonstrates meter consumption calculations, including register rollover.

### Task 2 — Data Types

Examines C data types, sizes, ranges and precision. Demonstrates unsigned meter arithmetic and the importance of integer-based monetary calculations.

### Task 3 — Constants

Defines electricity tariff values using macros and calculates bills according to the specified consumption slabs.

### Task 4 — Macros

Demonstrates safe macro definitions, macro expansion, square calculations and maximum-value calculations.

### Task 5 — Header Files and Conditional Compilation

Demonstrates header files, include guards and conditional debugging output using `#ifdef DEBUG`.

### Task 6 — Formatted Input and Output

Demonstrates formatted input, output and validation using `scanf()` and `printf()`.

### Task 7 — Type Conversion and Precision

Examines integer division, floating-point precision, explicit casting and type conversion.

### Task 8 — Compilation Process

Demonstrates preprocessing, assembly generation, object-file generation and executable creation using GCC.

### Task 9 — Billing Program Implementation and Testing

Implements the electricity billing calculation and tests consumption values, meter readings and input validation.

### Task 10 — Expected Results Versus Execution

Compares integer-paise, float and double calculations and examines the effect of precision and integer ranges.

### Task 11 — Final Design Recommendation

Recommends appropriate data types, tariff constants and program design choices for reliable electricity billing.

### Task 12 — Day-4 Design Challenge

Evaluates the smart-meter requirements, watt-hour readings, peak-hour tariffs and runtime-configurable tariff values.
